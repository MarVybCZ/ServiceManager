# ServiceManager
Windows service management

Project is still under construction!!!

## Requirements
- Windows 7 or later
- .NET Framework 4.6.1 or later  
- Administrator privileges (required for service management operations)

## What does this project do?
The idea is to have some manager for windows services and group of services. The user can create eg. group of services which he want to run/stop at office/home. When you arrive at home and want to watch a movie you don't need eg. SQL Server staff running. 

## Why is this project useful?
When this project be in prelease it will be possible to manage windows services and groups of services.

## Important Notes for Windows Users
- **Administrator Privileges**: This application requires administrator privileges to manage Windows services
- **UAC Prompt**: When launching the application, Windows will prompt for administrator elevation
- **Service Access**: The application needs access to Windows Service Control Manager
- **Permissions**: Some operations may fail without proper Windows permissions

## How do I get started?
1. Download the latest release
2. Right-click the executable and select "Run as administrator"
3. Accept the UAC prompt when prompted
4. The application will display a warning if not running with sufficient privileges
